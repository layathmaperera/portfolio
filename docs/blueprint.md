# **App Name**: CloudFolio

## Core Features:

- Project Showcase: Display personal and academic projects with detailed descriptions, tech stack, and links to repositories or live demos.
- Skills Section: List technical skills with proficiency levels and associated projects, demonstrating expertise. Offer dynamic filtering and search capabilities.
- About Me Section: A personalized 'About Me' section with a professional headshot, brief bio, and a link to download a detailed resume.
- Contact Form: Integrated contact form allowing visitors to send messages directly, with spam protection and email notifications.
- Tech Blog Integration: Link to personal tech blog feed or individual blog posts, displaying knowledge and insight in DevOps and cloud computing. Generative AI could be used as a tool to provide a brief TLDR (summarization) of posts.

## Style Guidelines:

- Primary color: Dark blue (#243A73) to establish a professional and reliable tone.
- Background color: Charcoal gray (#333333), providing a modern and sophisticated backdrop that complements the dark blue primary color.
- Accent color: Teal (#008080) for interactive elements and highlights, reflecting the app's tech focus and adding vibrancy against the darker backdrop.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look.
- Use clean, minimalist icons representing various tech skills and categories. Icons should be in teal or white to stand out against the dark background.
- A modern, single-page layout with smooth scrolling and clear section divisions, ensuring a seamless user experience.
- Subtle animations, such as hover effects and loading animations, to add polish and interactivity.
